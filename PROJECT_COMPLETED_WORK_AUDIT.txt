1. EXECUTIVE PROJECT SUMMARY
====================================================================================================
This project is an enterprise-grade catalog intelligence, scraping, media standardization, AI 
localization, and storefront synchronization engine connecting brand manufacturer websites directly 
to Baserow database tables and live Shopify e-commerce storefronts (Woonbloq ID: 1 and Binnen Design ID: 3).

Key Capabilities Already Built in Codebase:
- 28/28 Brand Scrapers built, tested, and operational via a unified domain router.
- Automated Background Removal & Canvas Sizing (1000x880 transparent hero, 1760x1100 white detail/lifestyle).
- OpenRouter GPT-4o Vision Image Classification (Hero, Detail, Lifestyle isolation).
- AI Dutch SEO Description & Translation Engine.
- Bidirectional Baserow <-> Shopify Synchronization Engine with metafield mapping.
- Native Python Model Context Protocol (MCP) Server for Claude AI catalog operations.

3. BASEROW DATABASE INTEGRATION & SCHEMA ARCHITECTURE
====================================================================================================
- `baserow_client.py`: Robust Baserow REST client supporting row creation, batched row fetching, 
  PATCH updates, row deletion, file uploads via multipart and direct URL upload, with retry handling.
- `product_baserow.py`: Object-relational mapper converting `ScrapedProduct` into Baserow table columns. 
  Handles relational linking to:
  * Brand Table (Table 805 / 745)
  * Category Table (Table 806)
  * Subcategory Table (Table 807)
  * Store Allocation Table (Table 8252)
- `product_schema.py`: Canonical Pydantic/Dataclass schemas for products, brands, categories.
- `discover_baserow.py` & `discover_baserow_relations.py`: Introspection scripts mapping table field IDs 
  and foreign key relations across databases.
- `migrate_database.py`: High-volume data migration script transferring rows between tables with field mapping.
- `clear_products_table.py`: Verified table cleaner utility with safety confirmation prompts.

====================================================================================================
4. IMAGE STANDARDIZATION & BACKGROUND PROCESSING ENGINES
====================================================================================================
- `fal_image_processor.py`:
  * `is_transparent_bg()`: Corner & edge alpha-channel inspector to detect pre-cut PNGs.
  * `process_master()`: Master image processor enforcing store dimensions:
    - Hero Images: 1000x880 canvas, 85% bounding-box margin scaling, transparent background (PNG).
    - Detail / Lifestyle Images: 1760x1100 canvas, centered subject smart-crop, pure white background (JPG).
  * `_smart_crop_center()`: Uses fal.ai bounding box to center product subject without cutting edges.
- `shopify_image_pipeline.py`: Multi-threaded batch processor classifying storefront images into Hero, 
  Detail, and Lifestyle buckets and updating Shopify metafields.
- `fal_image_processor.py`: fal.ai vision integration for automated background removal, FLUX lifestyle staging, and detail feature cropping.
- `test_unified_pipeline.py`: Comprehensive test harness combining:
  * GPT-4o Vision batch classification into Hero, Lifestyle, Detail.
  * fal.ai FLUX img2img / txt2img generative hero derivation for lifestyle-only products.
  * Automatic upload to Baserow file fields.

6. SHOPIFY STOREFRONT INTEGRATION & SYNC ENGINES
====================================================================================================
- `shopify_client.py`: Complete Shopify Admin REST client managing:
  * Product creation, updates, and draft status toggling.
  * Metafield updates (`custom.lifestyle_images`, `product_category`, `sub_category`).
  * Variant management, inventory level adjustments, and image gallery uploads.
- `baserow_shopify_sync.py`: Main synchronization pipeline connecting Baserow rows to Shopify:
  * Woonbloq Target (Store ID 1, Product ID `field_8302`, Status `field_8304`).
  * Binnen Design Target (Store ID 3, Product ID `field_8284`, Status `field_8283`).
  * Draft logic for incomplete products (missing hero, brand, or descriptions).
  * Lifestyle images isolated and attached to `metafields.custom.lifestyle_images`.

- `shopify_activate_products.py`: Activates draft products once QA passes.
- `shopify_draft_bg_products.py` & `shopify_draft_lifestyle.py`: Safety utilities moving non-compliant products to draft.
- `shopify_move_lifestyle_to_metafield_from_report.py`: Migrates lifestyle photos from product gallery to metafields.

====================================================================================================
7. AGENTIC CLAUDE MCP SUITE (MODEL CONTEXT PROTOCOL)
====================================================================================================
- `mcp_server.py`: Native Python Model Context Protocol (MCP) server enabling Claude AI to interact 
  directly with Baserow and Shopify:
  * `get_baserow_schema`: Inspect Baserow table structure, field IDs, and data types.
  * `search_baserow_products`: Keyword search across product name, description, and status.
  * `get_baserow_product`: Fetch full JSON record for a specific row ID.
  * `update_baserow_product`: Update field values in Baserow with required `confirm=True` safety guard.
  * `search_shopify_products`: Query live Shopify store by vendor, title, or status.
  * `get_shopify_product`: Inspect live Shopify product details, variants, and metafields.
  * `update_shopify_product`: Update title, body HTML, tags, or status with confirmation guard.
  * `update_shopify_inventory`: Adjust available stock quantities with out-of-stock safety prompt.
- `test_mcp_server.py`: Automated test suite verifying MCP tool execution over stdio.
